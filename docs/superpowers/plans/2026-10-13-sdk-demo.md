# sdk-demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a DA library plugin at `/tools/sdk-demo` that demonstrates `actions.sendText`, `actions.sendHTML` and `actions.getSelection`, individually and as a round trip, with a visible call log.

**Architecture:** A static HTML entry (`tools/sdk-demo.html`) holds all markup. One vanilla ES module (`tools/sdk-demo/sdk-demo.js`) awaits `DA_SDK`, enables the buttons, and wires each one to a small, commented demo function. One stylesheet handles the narrow library panel.

**Tech Stack:** Vanilla JS (ES modules, no build), DA App SDK `https://da.live/nx/utils/sdk.js`, ESLint (airbnb-base), Stylelint (standard).

**Spec:** `docs/superpowers/specs/2026-10-13-sdk-demo-design.md`

## Global Constraints

- **Files:** only `tools/sdk-demo.html`, `tools/sdk-demo/sdk-demo.js`, `tools/sdk-demo/sdk-demo.css`.
  No `package.json` changes. Never edit `scripts/aem.js`; it has unrelated uncommitted
  changes, so never `git add -A` or `git add .`.
- **SDK import:** `import DA_SDK from 'https://da.live/nx/utils/sdk.js';`, preceded by
  `// eslint-disable-next-line import/no-unresolved` (verified: lint fails without it).
  `sdk-demo.html` also loads `<script src="https://da.live/nx/utils/sdk.js" type="module">`
  before the demo script, per the DA docs.
- **Rendering:** never assign `innerHTML` and never insert selection HTML into the plugin
  document. Turn HTML into text only with
  `new DOMParser().parseFromString(html, 'text/html').body.textContent`.
- **Timeouts:** `CONNECT_TIMEOUT_MS = 3000`, `SELECTION_TIMEOUT_MS = 3000`.
- **Defaults:**
  - sendText textarea: `Hello from the SDK demo!`
  - sendHTML textarea: `<h2>Demo heading</h2><p>Some <strong>bold</strong> text.</p>`
- **Log prefixes:** `→` outgoing call, `←` result, `⚠` warning, `✕` error. Each entry is
  prefixed with the `HH:MM:SS` time.
- **Status copy:**
  - Initial: `Waiting for DA…`
  - On connect: `Connected: {org}/{repo}{path}`
  - After the connect timeout: `Open this plugin from the DA editor library.`
- **Timeout copy:** `No response — selection is probably empty (DA reports this on a channel
  the SDK doesn't listen to), or another message consumed the listener.`
- **Line endings:** files must use LF (`linebreak-style: unix`). If you create files on
  Windows, make sure they are LF.
- **Tests:** none automated, by user decision. Verification is lint, localhost load, and the
  manual DA checklist.

## Review Focus

1. **getSelection with nothing selected.** The SDK promise never settles. Expect a `⚠`
   timeout entry after about 3s and Get selection re-enabled, not a stuck disabled button.
   Pinned in Task 3, Step 3.
2. **Selection containing `<img onerror=...>` or `<script>`.** It must not execute in the
   plugin. Expect the raw HTML shown as literal text, and plain text derived via DOMParser.
   Pinned in Task 3, Step 3.
3. **Plugin opened directly (outside DA).** `DA_SDK` never resolves. Expect the fallback
   status after 3s and buttons that stay disabled. Pinned in Task 1, Step 3.
4. **Empty or whitespace-only textarea.** Expect a `⚠` log entry and no SDK call. Pinned in
   Task 2, Step 2.
5. **Round trip clicked after the user changes the editor selection.** The round trip uses
   the cached selection and replaces whatever is selected now. Expect the panel note to say
   "replaces the current editor selection". Pinned in Task 3, Step 3.

### Task 1: Plugin shell, SDK connection, status and log

**Files:**
- Create: `tools/sdk-demo.html`
- Create: `tools/sdk-demo/sdk-demo.js`
- Create: `tools/sdk-demo/sdk-demo.css`

**Interfaces:**
- Produces element IDs, all in `sdk-demo.html`:
  - `#status`
  - `#text-input`, `#send-text`
  - `#html-input`, `#send-html`
  - `#get-selection`, `#selection-html` (a `<pre>`), `#selection-text` (a `<pre>`)
  - `#rt-upper`, `#rt-strong`
  - `#log` (an `<ol>`), `#clear-log`
- Every SDK-calling button has class `sdk-action` and starts with the `disabled` attribute.
  `#clear-log` is not an SDK action.
- Produces in `sdk-demo.js` (module-private, used by Tasks 2–3):
  - `log(kind: 'out'|'in'|'warn'|'error', message: string): void` appends an `<li>` built
    with `textContent`: `${time} ${prefix} ${message}`, with class `log-${kind}`. Newest
    entry goes at the bottom, and the list scrolls into view.
  - `setStatus(text: string): void`
  - `$(id: string): HTMLElement` is a `document.getElementById` shorthand.
  - `init(): Promise<void>` is the entry point. Its first action wires `#clear-log` to empty
    `#log`, so Clear works even without DA. It then races `DA_SDK` against
    `CONNECT_TIMEOUT_MS`.
    - On timeout it sets the fallback status, then still awaits `DA_SDK` so that a late
      connection works.
    - On resolve it sets the connected status from `context.org`, `context.repo` and
      `context.path`, enables `.sdk-action` buttons except `#rt-upper` and `#rt-strong`,
      and calls `wireDemos(actions)`.
  - `wireDemos(actions): void` is a stub in this task. Tasks 2–3 add the listeners.

- [ ] **Step 1: Write `tools/sdk-demo.html`.**
  - Include the doctype, the viewport meta, and `<link rel="icon" href="data:,">`.
  - Use title `SDK Demo`.
  - Load the SDK `<script>`, then `/tools/sdk-demo/sdk-demo.js` as a module, and link
    `/tools/sdk-demo/sdk-demo.css`.
  - Add a top-of-file HTML comment holding the spec's "Registration" section verbatim (the
    library sheet row and the `?ref=local` note).
  - Build the body as `<main>` with:
    - `<p id="status">`
    - five `<section>`s (sendText, sendHTML, getSelection, round trip, log), each with an
      `<h2>` naming the call and a `<p class="note">`
    - the inputs and buttons listed under Interfaces, with the spec's note text for each
      panel
  - Put the default textarea values from Global Constraints in the markup. HTML-escape the
    sendHTML default inside `<textarea>`.

- [ ] **Step 2: Write `sdk-demo.js` (constants, `$`, `setStatus`, `log`, `init`, stub
  `wireDemos`) and `sdk-demo.css`.**
  - JS: start with a short header comment saying the file is a teaching reference for the DA
    App SDK. Call `init()` at module end.
  - CSS: system font, 13px base, full-width textareas and buttons, and
    `.log-warn` / `.log-error` colors.
  - CSS: scope every rule under `body` or a class. There's no block wrapper, so element
    selectors are fine here.

- [ ] **Step 3: Verify lint and the outside-DA fallback.**
  - Run `npx eslint tools` and `npx stylelint "tools/**/*.css"`. Expected: no output, exit 0.
  - Run `npx -y @adobe/aem-cli up` (async), then open
    `http://localhost:3000/tools/sdk-demo.html` in the browser tool.
  - Expected:
    - The status reads `Waiting for DA…`, then after about 3s
      `Open this plugin from the DA editor library.`
    - All `.sdk-action` buttons are disabled.
    - Clicking Clear works.
    - The console has no errors.

- [ ] **Step 4: Commit.**
  `git add tools/sdk-demo.html tools/sdk-demo/sdk-demo.js tools/sdk-demo/sdk-demo.css; git commit -m "feat(sdk-demo): plugin shell with SDK connection status and log"`

### Task 3: getSelection demo and round trip

**Files:**
- Modify: `tools/sdk-demo/sdk-demo.js`

**Interfaces:**
- Consumes: `$`, `log`, `demoSendText`, `demoSendHTML`, `wireDemos`, and
  `SELECTION_TIMEOUT_MS`.
- Produces:
  - `withTimeout(promise: Promise<T>, ms: number): Promise<T>` rejects with
    `new Error('timeout')` after `ms`.
  - `htmlToText(html: string): string` is DOMParser-based (see Global Constraints).
  - `demoGetSelection(actions): Promise<{ html: string, text: string } | null>`
  - A module-level `let lastSelection = null`.

- [ ] **Step 1: Implement `withTimeout` and `htmlToText`.**
  - Above `withTimeout`, add a comment explaining the SDK quirk: on an empty selection DA
    replies on the MessagePort, but `getSelection` listens on `window`; the listener also
    detaches on the first window message of any kind.

- [ ] **Step 2: Implement `demoGetSelection`.**
  - Disable `#get-selection` while the call is pending and re-enable it in `finally`.
  - Log `out` `getSelection()`, then await
    `withTimeout(actions.getSelection(), SELECTION_TIMEOUT_MS)`.
  - On success:
    - Set `#selection-html.textContent = html` and `#selection-text.textContent = text`.
    - Set `lastSelection`, enable `#rt-upper` and `#rt-strong`.
    - Log `in` `getSelection → "…"`, truncated to 80 characters.
  - On timeout: log `warn` with the timeout copy from Global Constraints.
  - On any other rejection: log `error` with `getSelection rejected: ${reason}`.
  - On either failure, return `null` and leave the previous `lastSelection` in place.

- [ ] **Step 3: Wire `#get-selection`, `#rt-upper` and `#rt-strong` in `wireDemos`; update
  the round-trip panel note; verify the Review Focus items.**
  - `#rt-upper` calls `demoSendText(actions, lastSelection.text.toUpperCase())`.
  - `#rt-strong` calls `demoSendHTML(actions, `<strong>${lastSelection.html}</strong>`)`.
  - The round-trip `.note` must say:
    `Uses the last fetched selection and replaces the current editor selection.`
  - Run `npx eslint tools`. Expected: exit 0.
  - Then run a throwaway harness. It stays in the session folder, is never committed, and
    must be deleted afterwards. It's a local HTML page that iframes
    `http://localhost:3000/tools/sdk-demo.html` and on iframe load:
    - Posts `{ ready: true, context: { org: 'o', repo: 'r', path: '/p' } }` with
      `[channel.port2]`.
    - Logs `port1` messages.
    - For `getSelection`, replies in one of two ways:
      - (a) `iframe.contentWindow.postMessage({ action: 'sendSelection',
        details: '<p>hi <img src=x onerror="alert(1)"></p>' }, '*')`
      - (b) no reply
  - Expected for (a):
    - The `<pre>` shows the literal HTML string.
    - The plain text shows `hi `.
    - No alert fires and no `x` image request is made.
    - The round-trip buttons are enabled. Clicking them posts `sendText` `HI ` and
      `sendHTML` `<strong><p>hi <img …></p></strong>` on the port.
  - Expected for (b): a `⚠` timeout entry after about 3s and Get selection re-enabled.

- [ ] **Step 4: Commit.**
  `git add tools/sdk-demo/sdk-demo.js tools/sdk-demo.html; git commit -m "feat(sdk-demo): getSelection demo with timeout and round trip"`
